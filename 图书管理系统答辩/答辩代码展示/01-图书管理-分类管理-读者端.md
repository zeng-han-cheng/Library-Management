# 01 图书管理、分类管理、读者端

## 一、模块定位

本模块负责图书基础资料维护、图书分类维护以及读者账户管理。前端使用 Vue 3 + Element Plus，后端使用 Spring Boot + MyBatis，数据持久化到 MySQL。

核心源码：

- 前端页面：`frontend/src/views/Books.vue`、`frontend/src/views/Categories.vue`、`frontend/src/views/Readers.vue`
- 控制器：`src/main/java/com/library/controller/BookController.java`、`CategoryController.java`、`ReaderController.java`
- 业务层：`src/main/java/com/library/service/impl/BookServiceImpl.java`、`CategoryServiceImpl.java`、`ReaderServiceImpl.java`
- 数据访问：`src/main/resources/mapper/BookMapper.xml`、`CategoryMapper.xml`、`ReaderMapper.xml`

## 二、图书管理

### 1. 前端查询与分页

文件：`frontend/src/views/Books.vue`

```javascript
async function load() {
  const response = await http.get('/books', {
    params: {
      page: page.value,
      size: 10,
      keyword: keyword.value
    }
  })
  rows.value = response.data.records
  total.value = response.data.total
}
```

前端将页码、分页大小和关键字作为查询参数发送，后端返回统一的分页结构：`total + records`。

### 2. 后端分页接口

文件：`src/main/java/com/library/controller/BookController.java`

```java
@GetMapping
public ApiResult<PageResult<BookVO>> page(BookQuery query) {
    return ApiResult.success(service.page(query));
}

@PostMapping
@RequireRole(RoleConstant.ADMIN)
public ApiResult<Void> save(@Valid @RequestBody Book book) {
    service.save(book);
    return ApiResult.success();

```

查询接口允许登录用户访问；新增、修改和删除接口通过 `@RequireRole(ADMIN)` 限制为管理员。

### 3. 库存初始化与更新规则

文件：`src/main/java/com/library/service/impl/BookServiceImpl.java`

```java
@Override
public void save(Book book) {
    int totalStock = book.getTotalStock() == null ? 0 : book.getTotalStock();
    book.setTotalStock(totalStock);
    book.setAvailableStock(totalStock);
    book.setStatus(totalStock > 0 ? 1 : 2);
    if (mapper.insert(book) != 1) {
        throw new BusinessException("新增图书失败");
    }
}

@Override
public void update(Book book) {
    Book oldBook = mapper.findById(book.getId());
    int borrowedCount = oldBook.getTotalStock() - oldBook.getAvailableStock();
    int totalStock = book.getTotalStock() == null
            ? oldBook.getTotalStock() : book.getTotalStock();
    if (totalStock < borrowedCount) {
        throw new BusinessException("总库存不能小于已借数量");
    }
    book.setTotalStock(totalStock);
    book.setAvailableStock(totalStock - borrowedCount);
    book.setStatus(book.getAvailableStock() > 0 ? 1 : 2);
    mapper.update(book);
}
```

答辩时可以强调：库存不是由前端直接决定，而是在业务层根据“总库存”和“已借数量”重新计算可借库存，避免修改图书时出现库存倒挂。

### 4. MyBatis 条件查询

文件：`src/main/resources/mapper/BookMapper.xml`

```xml
<select id="page" resultType="BookVO">
  SELECT b.*, c.name category_name
  FROM book b
  JOIN category c ON b.category_id = c.id
  WHERE (#{keyword} IS NULL
      OR b.title LIKE CONCAT('%', #{keyword}, '%')
      OR b.author LIKE CONCAT('%', #{keyword}, '%')
      OR b.isbn LIKE CONCAT('%', #{keyword}, '%'))
    AND (#{categoryId} IS NULL OR b.category_id = #{categoryId})
    AND (#{status} IS NULL OR b.status = #{status})
  ORDER BY b.id DESC
  LIMIT #{offset}, #{limit}
</select>
```

该查询同时支持书名、作者、ISBN、分类和状态筛选，并使用分页参数降低一次性查询的数据量。

## 三、分类管理

### 1. REST 接口和角色控制

文件：`src/main/java/com/library/controller/CategoryController.java`

```java
@RestController
@RequestMapping("/api/categories")
@RequireRole({RoleConstant.ADMIN, RoleConstant.READER})
public class CategoryController {
    @GetMapping
    public ApiResult<List<Category>> list() {
        return ApiResult.success(service.list());
    }

    @PostMapping
    @RequireRole(RoleConstant.ADMIN)
    public ApiResult<Void> save(@RequestBody Category category) {
        service.save(category);
        return ApiResult.success();
    }
}
```

分类列表对管理员和读者开放，分类新增、修改和删除只允许管理员执行。这样读者端可以按分类浏览图书，但不能修改基础数据。

### 2. 业务校验

文件：`src/main/java/com/library/service/impl/CategoryServiceImpl.java`

```java
@Override
public void save(Category category) {
    if (category == null || category.getName() == null
            || category.getName().isBlank()) {
        throw new BusinessException("分类名称不能为空");
    }
    if (mapper.insert(category) != 1) {
        throw new BusinessException("新增分类失败");
    }
}
```

控制器负责接收请求，业务层负责校验规则，Mapper 负责执行 SQL，体现了 Controller、Service、Mapper 分层。

## 四、读者端

### 1. 读者管理页面

文件：`frontend/src/views/Readers.vue`

```javascript
async function load() {
  const response = await http.get('/readers', {
    params: {
      page: page.value,
      size: 10,
      keyword: keyword.value
    }
  })
  rows.value = response.data.records
  total.value = response.data.total
}

async function save() {
  const response = form.id
    ? await http.put('/readers', form)
    : await http.post('/readers', form)
  if (response.code === 200) await load()
}
```

页面通过 `form.id` 区分新增和编辑，保存成功后重新加载分页数据，保证列表显示最新状态。

### 2. 密码加密

文件：`src/main/java/com/library/service/impl/ReaderServiceImpl.java`

```java
public void save(Reader reader) {
    if (reader.getPassword() != null) {
        reader.setPassword(encoder.encode(reader.getPassword()));
    }
    if (reader.getMaxBorrow() == null) {
        reader.setMaxBorrow(5);
    }
    mapper.insert(reader);
}

public void update(Reader reader) {
    if (reader.getPassword() != null && !reader.getPassword().isBlank()) {
        reader.setPassword(encoder.encode(reader.getPassword()));
    }
    mapper.update(reader);
}
```

系统保存的是 BCrypt 密文，不保存明文密码；编辑读者时如果密码为空，则保留原密码。

## 

1. 图书查询采用分页和多条件筛选，适合库存数据量增长后的场景。
2. 库存状态由后端业务层统一计算，借阅和归还时再通过事务更新库存。
3. 分类和读者管理使用角色权限控制，读者只能查看和使用允许的功能。
4. 密码使用 BCrypt 加密，前后端通过统一的 `ApiResult` 结构通信。
