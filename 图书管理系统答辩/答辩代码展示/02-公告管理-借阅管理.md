# 02 公告管理、借阅管理

## 一、模块定位

本模块实现管理员发布公告、读者查看公告，以及图书借阅、归还、逾期状态展示。借阅是系统的核心业务，重点体现权限校验、库存一致性和事务控制。

核心源码：

- 前端页面：`frontend/src/views/Notices.vue`、`frontend/src/views/Borrows.vue`
- 控制器：`NoticeController.java`、`BorrowController.java`
- 业务层：`NoticeServiceImpl.java`、`BorrowServiceImpl.java`
- SQL 映射：`NoticeMapper.xml`、`BorrowMapper.xml`、`BookMapper.xml`

## 二、公告管理

### 1. 公告发布和公开查询

文件：`src/main/java/com/library/controller/NoticeController.java`

```java
@GetMapping("/public")
public ApiResult<List<Notice>> publicList() {
    return ApiResult.success(service.publicList());
}

@PostMapping
@RequireRole(RoleConstant.ADMIN)
public ApiResult<Void> save(@RequestBody Notice notice) {
    service.save(notice);
    return ApiResult.success();

```

公告公开列表不要求管理员权限；发布、修改和删除公告需要管理员权限。`WebConfig` 同时将 `/api/notices/public` 排除出登录拦截器，便于登录前展示公共公告。

### 2. 发布时记录时间

文件：`src/main/java/com/library/service/impl/NoticeServiceImpl.java`

```java
@Override
public void save(Notice notice) {
    if (notice == null || notice.getTitle() == null
            || notice.getTitle().isBlank()
            || notice.getContent() == null
            || notice.getContent().isBlank()
            || notice.getAdminId() == null) {
        throw new BusinessException("公告标题、内容和发布人不能为空");
    }
    if (Integer.valueOf(1).equals(notice.getPublishStatus())) {
        notice.setPublishedAt(LocalDateTime.now());
    }
    mapper.insert(notice);
}
```

草稿和已发布公告使用 `publishStatus` 区分；只有正式发布时才记录 `publishedAt`。

### 3. 公告 SQL

文件：`src/main/resources/mapper/NoticeMapper.xml`

```xml
<select id="publicList" resultType="Notice">
  SELECT *
  FROM notice
  WHERE publish_status = 1
  ORDER BY published_at DESC, id DESC
</select>
```

公开页面只查询已发布公告，并按发布时间倒序排列。

## 三、借阅管理

### 1. 借阅接口和读者身份隔离

文件：`src/main/java/com/library/controller/BorrowController.java`

```java
@PostMapping
@RequireRole({RoleConstant.ADMIN, RoleConstant.READER})
public ApiResult<Void> borrow(@Valid @RequestBody BorrowDTO request) {
    LoginUser user = UserContext.get();
    Long readerId = RoleConstant.READER.equals(user.getRole())
            ? user.getId() : request.readerId();
    if (readerId == null) {
        throw new BusinessException("请选择读者");
    }
    service.borrow(new BorrowDTO(
            readerId, request.bookId(), request.days(),
            request.quantity(), request.remark()));
    return ApiResult.success();
}
```

管理员可以为指定读者办理借阅；读者端不能通过修改请求参数替其他读者借书，后端会直接使用 JWT 中的当前用户 ID。

### 2. 借阅业务事务

文件：`src/main/java/com/library/service/impl/BorrowServiceImpl.java`

```java
@Override
@Transactional(rollbackFor = Exception.class)
public void borrow(BorrowDTO request) {
    Reader reader = readerMapper.findById(request.readerId());
    if (reader == null || !Integer.valueOf(1).equals(reader.getStatus())) {
        throw new BusinessException("读者不存在或已被禁用");
    }

    int quantity = request.quantity() == null ? 1 : request.quantity();
    int borrowingCount = readerMapper.countBorrowing(request.readerId());
    if (borrowingCount + quantity > reader.getMaxBorrow()) {
        throw new BusinessException("借阅数量超过上限");
    }

    Book book = bookMapper.findById(request.bookId());
    if (book == null || book.getAvailableStock() < quantity) {
        throw new BusinessException("可借库存不足");
    }

    for (int index = 0; index < quantity; index++) {
        if (bookMapper.decreaseStock(request.bookId()) != 1) {
            throw new BusinessException("库存更新失败，请重试");
        }
        BorrowRecord record = new BorrowRecord();
        record.setReaderId(request.readerId());
        record.setBookId(request.bookId());
        record.setDueTime(LocalDateTime.now().plusDays(
                request.days() == null ? 30 : request.days()));
        record.setStatus(1);
        record.setRemark(request.remark());
        borrowMapper.insert(record);
    }
}
```

`@Transactional` 保证“扣减库存”和“写入借阅记录”要么全部成功，要么全部回滚，避免出现库存减少但没有借阅记录的脏数据。

### 3. 归还业务

文件：`src/main/java/com/library/service/impl/BorrowServiceImpl.java`

```java
@Override
@Transactional(rollbackFor = Exception.class)
public void returnBook(ReturnDTO request) {
    BorrowRecord record = borrowMapper.findById(request.recordId());
    if (record == null || !Integer.valueOf(1).equals(record.getStatus())) {
        throw new BusinessException("借阅记录不存在或已经归还");
    }

    record.setStatus(request.status());
    record.setReturnTime(LocalDateTime.now());
    record.setRemark(request.remark());
    if (borrowMapper.returnBook(record) != 1
            || bookMapper.increaseStock(record.getBookId()) != 1) {
        throw new BusinessException("归还失败，请重试");
    }
}
```

归还时同时更新借阅记录状态、归还时间和图书可借库存；正常归还与异常归还通过不同状态值区分。

### 4. 库存 SQL 的并发保护

文件：`src/main/resources/mapper/BookMapper.xml`

```xml
<update id="decreaseStock">
  UPDATE book
  SET available_stock = available_stock - 1,
      status = IF(available_stock - 1 &gt; 0, 1, 2)
  WHERE id = #{id}
    AND available_stock &gt; 0
</update>

<update id="increaseStock">
  UPDATE book
  SET available_stock = LEAST(total_stock, available_stock + 1),
      status = IF(available_stock + 1 &gt; 0, 1, 2)
  WHERE id = #{id}
</update>
```

扣减库存带有 `available_stock > 0` 条件，归还库存不允许超过总库存，从 SQL 层进一步保护库存边界。

## 四、前端交互

文件：`frontend/src/views/Borrows.vue`

```javascript
async function borrow() {
  if (!borrowForm.bookId) return
  if (borrowForm.quantity > quantityLimit.value) return

  submitting.value = true
  try {
    const response = await http.post('/borrows', borrowForm)
    if (response.code !== 200) throw new Error(response.message)
    borrowVisible.value = false
    await load()
  } finally {
    submitting.value = false
  }
}

async function returnBook(row, status) {
  const response = await http.put('/borrows/return', {
    recordId: row.id,
    status
  })
  if (response.code === 200) await load()
}
```

前端负责表单交互、按钮状态和结果刷新，真正的借阅上限、读者身份、库存和事务校验全部放在后端完成。



1. 公告采用“公开查询 + 管理员维护”的接口设计，满足登录前查看公告的需求。
2. 借阅业务通过 JWT 识别当前读者，防止越权代借和越权归还。
3. 借阅和归还使用 Spring 事务，保证借阅记录与库存的一致性。
4. SQL 使用库存边界条件，事务和数据库条件共同防止库存超借、归还超量。
